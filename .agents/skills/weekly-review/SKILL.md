# Weekly review

Goal: prove what stuck this week, from memory, and fix the plan for next week.

1. **Read** `PROGRESS.md` and this week's `sessions/` notes.
2. **Quiz from memory:** 8–10 questions, weighted to Shaky / Not done modules and the review queue. Mix tracks (interleave). One at a time; grade each.
3. **Speak:** one full real-app answer out loud from `real-apps/`: first a 2-minute version, then a 10-minute version with schema, failure handling and trade-offs. Grade both.
4. **Bigger task (1–2 hours):** one exercise combining the week's modules, ideally a multi-file bug hunt (follow `$bug-hunt` for the format).
5. **Track R check:** count this week's bug hunts, code-reading drill, postmortem and any open-source work against the rhythm in `SYLLABUS.md`. Name what's missing.
6. **Plan:** update `PROGRESS.md`: statuses, review queue dates, "Next session". Suggest one change for next week if something isn't working, but only change the Path if I agree.
7. **Close:** run the "Done means" checklist in `AGENTS.md` and list changed files.
