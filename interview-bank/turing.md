# Interview bank: Turing

Source: turing.com/blog/turing-developer-test-preparation-tips (checked 22 Nov 2026). Topics summarised in my own words.

## Test format
1. Profile and resume.
2. Work-experience survey (multiple choice, about 20–30 minutes).
3. **Tech-stack tests** (multiple choice, 45–120 minutes). Some questions have more than one right answer. Stacks include React JS, React Hooks and Node JS. A failed stack test can only be retaken after **three months**, so I take it only when quick checks are steady at 4/5 or better.
4. **Live coding challenge** (real time). Practised through M8 timed drills.

Some applications also add a timed coding assessment (about 44 minutes in an online editor). Don't start it until timed drills feel routine.
